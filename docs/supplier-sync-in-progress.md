# Автоматическая передача поставщиков: подготовка, не подключена

Это заготовка, не работающая синхронизация. На ai.michael.kz продолжает действовать последний вручную активированный снимок. Не публиковать эти части как готовую функцию.

- `catalog-bridge/supplier-delta.mjs` строит план изменений по точным ID предложения и источника, не меняет склад и отдельно отмечает отсутствующие/новые/устаревшие записи.
- `worker/src/lib/supplier-sync-plan.ts` проверяет и применяет изменения к копии страницы, сохраняя остальные поля и подтверждённые связи. Модуль не подключён к сетевым маршрутам.
- Покрытие: synthetic tests и опциональный прогон на приватном снимке 45 811 предложений. Файл снимка и приватные данные не добавлены в Git.

Следующие обязательные шаги: защищённое узкоспециализированное подключение к локальному серверу; надёжное чтение актуального IndexedDB именно того браузера, где ведётся каталог, без потери ручных данных; безопасное хранилище учётных данных; ограничение частоты и пообъектное хранение/версионирование страниц вместо постоянной полной перезаписи; атомарная активация с проверкой исходного снимка при параллельном ручном импорте; возобновление при сбое; учёт новых и отсутствующих товаров без ложного удаления; график истории, видимый после автоматического обновления; проверка на изолированной D1 и затем с разрешёнными тестовыми данными в production. Все запросы должны использовать действующую авторизацию и не создавать служебные администраторские сессии.

При проверке 29.10.2026 локальный сервер 4381 не был запущен; он запущен без пересборки. После перезапуска общий ключ Apicore отсутствует в памяти. Для четырёх дистрибьюторов сохраняются старые снимки, новые данные недоступны до повторного ввода ключа пользователем. Поставщики с XLS требуют новый файл, предоставленный поставщиком. Рабочая 1С не подменяется тестовой.

## Почему не включён полный импорт по таймеру

Проверенный экспорт содержит 45 811 предложений и около 44,5 МБ; ежечасное создание полной копии дало бы более 1 ГБ в сутки без учёта индексов и прочих данных. Для бесплатной базы такой режим быстро заполнит хранилище. Перед включением требуется повторное использование неизменённых страниц и устойчивый журнал подтверждённых изменений, с проверкой актуальной версии при одновременном ручном импорте.
